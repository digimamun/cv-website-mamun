# Professional CV Website

This is a modern, responsive CV website created by LLM for Mohammad Sardar Mamun.

## Files
- `index.html` — landing page with CV content and contact details
- `styles.css` — responsive styling and layout
- `script.js` — mobile navigation behavior
- `assets/CV of Mohammad Sardar Mamun 310326.pdf` — downloadable resume PDF

## How to use
1. Open `index.html` in a browser.
2. Or deploy the folder to a free static hosting provider.

## Deployment options
- GitHub Pages: push this repository and enable Pages in GitHub settings.
- Netlify: drag and drop the project folder into Netlify deploy.
- Vercel: import the folder as a static site.

## Notes
The website is built using HTML, CSS, and JavaScript and is ready for free static hosting.
